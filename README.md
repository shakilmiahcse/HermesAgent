# Hermes - AI Growth Intelligence System (Fluento)

উইন্ডোজ ১০ এনভায়রনমেন্টে Docker-এর সাহায্যে **Hermes Agent** চালনার জন্য এই প্রজেক্টটি কনফিগার করা হয়েছে। এটি সম্পূর্ণ লিনাক্স-সামঞ্জস্যপূর্ণ এবং পরবর্তীতে কোনো বড় পরিবর্তন ছাড়াই লিনাক্স ভিপিএস (Linux VPS)-এ মাইগ্রেশন করার উপযোগী।

---

## ১. প্রজেক্ট ফোল্ডার স্ট্রাকচার (Folder Structure)

প্রজেক্টের মূল ডিরেক্টরি লেআউট নিচে দেওয়া হলো (যেখানে **Engine** এবং **Workspace** সম্পূর্ণ আলাদা করা হয়েছে):

```text
Hermes/ (রুট ফোল্ডার)
├── hermes-agent/           # Engine: NousResearch-এর অফিসিয়াল রিপোজিটরি ক্লোন
├── workspace/              # Workspace: Fluento-র সমস্ত ডাটা ও কনফিগারেশন ফাইল
│   ├── config/             # Hermes কনফিগারেশন ফাইলসমূহ
│   ├── data/               # মূল ডেটা স্টোরেজ ও ফাইল পারসিস্টেন্স
│   ├── logs/               # Hermes রানটাইম লগ ফাইল
│   ├── memory/             # এআই মেমরি স্টোরেজ
│   ├── prompts/            # সিস্টেম এবং কাস্টম এআই প্রম্পট
│   ├── reports/            # এআই দ্বারা জেনারেট করা রিপোর্টসমূহ
│   ├── skills/             # কাস্টম এআই স্কিলসমূহ
│   ├── sops/               # SOP গাইডসমূহ
│   ├── templates/          # রিপোর্ট ও ইমেল টেমপ্লেট
│   ├── workflows/          # কাস্টম অটোমেশন ওয়ার্কফ্লো
│   ├── Dockerfile          # কাস্টমাইজড Dockerfile (লাইন এন্ডিং ও পারমিশন ফিক্সসহ)
│   └── .env                # সংবেদনশীল এপিআই কি ও ক্রেডেনশিয়াল (গিট-ইগনোরড)
├── .gitignore              # রুট গিট ইগনোর ফাইল
├── docker-compose.yml      # ডকার কম্পোজ কনফিগারেশন ফাইল
└── README.md               # প্রজেক্ট গাইড (এই ফাইলটি)
```

## ২. প্রাক-প্রয়োজনীয়তা (Prerequisites)
কাজ শুরু করার আগে নিশ্চিত করুন যে আপনার উইন্ডোজ মেশিনে নিচের টুলগুলো ইনস্টল ও রানিং আছে:
- **Docker Desktop** (অবশ্যই রানিং থাকতে হবে, যা ব্যাকএন্ড হিসেবে WSL2 ব্যবহার করে)।
- **Git** (রিপোজিটরি কন্ট্রোলের জন্য)।
- **Python 3.10+** এবং **Node.js** (লোকাল ইউটিলিটি স্ক্রিপ্ট রান করার জন্য)।

## ৩. কিভাবে শুরু করবেন (How to Start Hermes)

১. প্রথমে `workspace/.env` ফাইলটি খুলুন এবং আপনার LLM Provider (যেমন: OpenRouter, OpenAI, বা Anthropic) এর API Key বসান।
২. Docker Desktop অ্যাপ্লিকেশনটি উইন্ডোজে চালু করুন।
৩. প্রজেক্ট ডিরেক্টরিতে পাওয়ারশেল (PowerShell) ওপেন করে নিচের কমান্ডটি চালান:
   ```powershell
   docker compose up -d
   ```
৪. এটি সফলভাবে সম্পন্ন হলে ব্রাউজার ওপেন করুন:
   - **Hermes Web UI / Dashboard:** `http://localhost:9119`
   - **API Gateway:** `http://localhost:8642`

> **নিরাপত্তা ও অথেন্টিকেশন (June 2026 Security Update):**

> - **Username:** `admin`

## ৪. কিভাবে বন্ধ করবেন (How to Stop Hermes)

Hermes এর কন্টেইনারগুলো বন্ধ এবং স্টপ করতে নিচের কমান্ডটি রান করুন:
```powershell
docker compose down
```

---

## ۵. কিভাবে আপডেট করবেন (How to Update)

Hermes Agent-এর নতুন ভার্সন এলে ডকার ইমেজ এবং রিপোজিটরি আপডেট করতে নিচের ধাপগুলো অনুসরণ করুন:

১. `hermes-agent` (Engine) ডিরেক্টরিতে গিয়ে আপডেট করুন:
   ```powershell
   cd hermes-agent
   git pull origin main
   cd ..
   ```
২. কন্টেইনার পুনরায় বিল্ড এবং স্টার্ট করুন:
   ```powershell
   docker compose up -d --build
   ```

---

## ৬. কিভাবে ব্যাকআপ নিবেন (How to Backup)

যেকোনো বড় আপগ্রেডের আগে আপনার ডেটা এবং কনফিগারেশন ব্যাকআপ নেওয়া জরুরি। ব্যাকআপ নেওয়ার জন্য `workspace` ফোল্ডারটি কপি করে `backups` ডিরেক্টরিতে রাখতে পারেন:
```powershell
Copy-Item -Path .\workspace -Destination .\workspace-backup-$(Get-Date -Format "yyyyMMdd-HHmmss") -Recurse
```

---

## ৭. কিভাবে লগ ফাইল দেখবেন (How to View Logs)

যেকোনো সমস্যা নির্ণয় বা এআই এর কার্যক্রম ট্র্যাক করতে রানটাইম লগ দেখতে পারেন:

- **লাইভ ডকার লগ দেখার জন্য:**
  ```powershell
  docker compose logs -f
  ```
- **শুধুমাত্র ড্যাশবোর্ড বা গেটওয়ের লগ দেখতে:**
  ```powershell
  docker compose logs -f dashboard
  # অথবা
  docker compose logs -f gateway
  ```
- এছাড়াও লোকাল `workspace/logs/` ডিরেক্টরিতে বিস্তারিত লগ সংরক্ষিত থাকে।

## ৮. ভবিষ্যৎ লিনাক্স ভিপিএস মাইগ্রেশন গাইড (Linux VPS Migration Guide)

লিনাক্স প্রোডাকশন ভিপিএস (Linux VPS)-এ স্থানান্তর করার ক্ষেত্রে নিচের গাইডলাইনটি অনুসরণ করুন:

১. **ডিরেক্টরি বিন্যাস:**
   সার্ভারের `/opt/hermes/` ফোল্ডারের ভেতরে `engine/` (অফিশিয়াল hermes-agent ক্লোন) এবং `workspace/` (আপনার গিটহাব রিপোজিটরির ক্লোন) ফোল্ডার দুটি আলাদা রাখুন।
২. **ডকার কম্পোজ কাস্টমাইজেশন:**
   সার্ভারে `docker-compose.yml` ফাইলের build context পরিবর্তন করে `./engine` করুন।
৩. **ভলিউম ম্যাপিং:**
   নিশ্চিত করুন যে সব ভলিউম `./workspace/...` পাথের সাথে সঠিকভাবে ম্যাপ করা আছে।
৪. **রানিং কমান্ড:**
   সার্ভারে রান করতে নিচের কমান্ডটি ব্যবহার করুন:
   ```bash
   docker compose up -d --build
   ```
৫. **HTTPS ও রিভার্স প্রক্সি:**
   প্রোডাকশনে ড্যাশবোর্ড সরাসরি উন্মুক্ত করার পূর্বে অবশ্যই Apache বা Nginx দিয়ে একটি রিভার্স প্রক্সি তৈরি করে Let's Encrypt SSL-এর মাধ্যমে HTTPS সিকিউর করে নিবেন।
