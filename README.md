# Hermes - AI Growth Intelligence System (Fluento)

উইন্ডোজ ১০ এনভায়রনমেন্টে Docker-এর সাহায্যে **Hermes Agent** চালনার জন্য এই প্রজেক্টটি কনফিগার করা হয়েছে। এটি সম্পূর্ণ লিনাক্স-সামঞ্জস্যপূর্ণ এবং পরবর্তীতে কোনো বড় পরিবর্তন ছাড়াই লিনাক্স ভিপিএস (Linux VPS)-এ মাইগ্রেশন করার উপযোগী।

## ১. প্রজেক্ট ফোল্ডার স্ট্রাকচার (Folder Structure)

প্রজেক্টের মূল ডিরেক্টরি লেআউট নিচে দেওয়া হলো:

```text
hermes/
├── docker/                 # কাস্টম ডকার ফাইলসমূহ (ভবিষ্যতের প্রয়োজনের জন্য)
├── config/                 # Hermes কনফিগারেশন ফাইলসমূহ
├── prompts/                # সিস্টেম এবং কাস্টম এআই প্রম্পট
├── reports/                # এআই দ্বারা জেনারেট করা রিপোর্টসমূহ
├── workflows/              # কাস্টম অটোমেশন ওয়ার্কফ্লো
├── logs/                   # Hermes রানটাইম লগ ফাইল
├── data/                   # মূল ডেটা স্টোরেজ ও ফাইল পারসিস্টেন্স
│   └── config.yaml         # সক্রিয় কনফিগারেশন ফাইল
├── memory/                 # এআই মেমরি স্টোরেজ
├── skills/                 # এআই কাস্টম স্কিলসমূহ
├── knowledge/              # নলেজ বেস ফাইলসমূহ
├── scripts/                # ইউটিলিটি স্ক্রিপ্টসমূহ
├── backups/                # কনফিগারেশন ও ডেটা ব্যাকআপ
├── mcp/                    # MCP সার্ভার ইন্টিগ্রেশন গাইড ও কনফিগারেশন
│   └── README.md           # MCP সেটআপ গাইড
├── hermes-agent/           # NousResearch-এর অফিসিয়াল রিপোজিটরি ক্লোন
├── .env                    # সংবেদনশীল এপিআই কি ও ক্রেডেনশিয়াল (গিট-ইগনোরড)
├── .env.example            # এনভায়রনমেন্ট ফাইলের টেমপ্লেট উদাহরণ
├── docker-compose.yml      # ডকার কম্পোজ কনফিগারেশন ফাইল
└── README.md               # প্রজেক্ট গাইড (এই ফাইলটি)
```

## ২. প্রাক-প্রয়োজনীয়তা (Prerequisites)
কাজ শুরু করার আগে নিশ্চিত করুন যে আপনার উইন্ডোজ মেশিনে নিচের টুলগুলো ইনস্টল ও রানিং আছে:
- **Docker Desktop** (অবশ্যই রানিং থাকতে হবে, যা ব্যাকএন্ড হিসেবে WSL2 ব্যবহার করে)।
- **Git** (রিপোজিটরি কন্ট্রোলের জন্য)।
- **Python 3.10+** এবং **Node.js** (লোকাল ইউটিলিটি স্ক্রিপ্ট রান করার জন্য)।

## ৩. কিভাবে শুরু করবেন (How to Start Hermes)

১. প্রথমে `.env` ফাইলটি খুলুন এবং আপনার LLM Provider (যেমন: OpenRouter, OpenAI, বা Anthropic) এর API Key বসান।
২. Docker Desktop অ্যাপ্লিকেশনটি উইন্ডোজে চালু করুন।
৩. প্রজেক্ট ডিরেক্টরিতে পাওয়ারশেল (PowerShell) ওপেন করে নিচের কমান্ডটি চালান:
   ```powershell
   docker compose up -d
   ```
৪. এটি সফলভাবে সম্পন্ন হলে ব্রাউজার ওপেন করুন:
   - **Hermes Web UI / Dashboard:** `http://localhost:9119`
   - **API Gateway:** `http://localhost:8642`

> **নিরাপত্তা ও অথেন্টিকেশন (June 2026 Security Update):**

> - **Username:** `admin`
> - **Password:** `fluentogrowth`
> ড্যাশবোর্ডে লগইন করার জন্য এই ক্রেডেনশিয়ালগুলো ব্যবহার করুন।

## ৪. কিভাবে বন্ধ করবেন (How to Stop Hermes)

Hermes এর কন্টেইনারগুলো বন্ধ এবং স্টপ করতে নিচের কমান্ডটি রান করুন:
```powershell
docker compose down
```

---

## ৫. কিভাবে আপডেট করবেন (How to Update)

Hermes Agent-এর নতুন ভার্সন এলে ডকার ইমেজ এবং রিপোজিটরি আপডেট করতে নিচের ধাপগুলো অনুসরণ করুন:

১. `hermes-agent` রিপোজিটরি আপডেট করুন:
   ```powershell
   cd hermes-agent
   git pull origin main
   cd ..
   ```
২. সর্বশেষ ডকার ইমেজ পুল করুন:
   ```powershell
   docker compose pull
   ```
৩. কন্টেইনার পুনরায় বিল্ড এবং স্টার্ট করুন:
   ```powershell
   docker compose up -d --force-recreate
   ```

## ৬. কিভাবে ব্যাকআপ নিবেন (How to Backup)

যেকোনো বড় আপগ্রেডের আগে আপনার ডেটা এবং কনফিগারেশন ব্যাকআপ নেওয়া জরুরি। ব্যাকআপ নেওয়ার জন্য `data` ফোল্ডারটি কপি করে `backups` ডিরেক্টরিতে রাখতে পারেন:
```powershell
Copy-Item -Path .\data -Destination .\backups\data-backup-$(Get-Date -Format "yyyyMMdd-HHmmss") -Recurse
```

## ৭. কিভাবে লগ ফাইল দেখবেন (How to View Logs)

যেকোনো সমস্যা নির্ণয় বা এআই এর কার্যক্রম ট্র্যাক করতে রানটাইম লগ দেখতে পারেন:

- **লাইভ ডকার লগ দেখার জন্য:**
  ```powershell
  docker compose logs -f
  ```
- **শুধুমাত্র ড্যাশবোর্ড বা গেটওয়ের লগ দেখতে:**
  ```powershell
  docker compose logs -f dashboard
  # অথবা
  docker compose logs -f gateway
  ```
- এছাড়াও লোকাল `logs/` ডিরেক্টরিতে বিস্তারিত লগ সংরক্ষিত থাকে।

## ৮. ট্রাবলশুটিং (Troubleshooting)

### কন্টেইনার স্টার্ট হচ্ছে না (Docker Desktop Error)
- **কারণ:** Docker Desktop ব্যাকগ্রাউন্ডে রানিং নেই।
- **সমাধান:** উইন্ডোজ সার্চ বারে "Docker Desktop" লিখে সার্চ করে চালু করুন। কন্টেইনার রান করার পূর্বে নিচে সবুজ "Engine Running" সাইনটি দেখে নিশ্চিত হোন।

### ড্যাশবোর্ডে "401 Unauthorized" বা Bind Error
- **কারণ:** অ-অনুমোদিত কোনো আইপি বা হোস্ট থেকে ড্যাশবোর্ড সরাসরি অ্যাক্সেস করতে চাইলে সিকিউরিটি গেট এটি ব্লক করে।
- **সমাধান:** আমরা `data/config.yaml`-এ `dashboard.basic_auth` যুক্ত করেছি। লগইন করার সময় ইউজারনেম `admin` এবং পাসওয়ার্ড `fluentogrowth` ব্যবহার করুন।

## ৯. ভবিষ্যৎ লিনাক্স ভিপিএস মাইগ্রেশন নোট (Future Linux Migration Notes)

লোকাল উইন্ডোজ ডেভেলপমেন্ট পরিবেশ থেকে লিনাক্স প্রোডাকশন ভিপিএস (Linux VPS)-এ স্থানান্তর করার ক্ষেত্রে নিচের বিষয়গুলো মনে রাখবেন:

১. **ডকার কম্পোজ ব্যবহার:** লিনাক্স ভিপিএস-এ ঠিক একই কনফিগারেশনে রান করার জন্য এই পুরো রিপোজিটরি ক্লোন করে `docker compose up -d` রান করলেই হবে।
২. **নেটওয়ার্ক মোড:** লিনাক্স ভিপিএস-এ সরাসরি পারফরম্যান্সের জন্য `network_mode: host` ব্যবহার করতে পারেন যা আমাদের লোকাল উইন্ডোজ ডকার ডেস্কটপে সীমাবদ্ধতার কারণে আমরা এভয়েড করেছি।
৩. **ভলিউম পাথ:** লিনাক্সে ভলিউম পাথ হিসেবে ব্যবহারকারীর হোম ডিরেক্টরি `~/.hermes` বা সরাসরি `./data` পাথ মাউন্ট করবেন।
৪. **HTTPS ও রিভার্স প্রক্সি:** প্রোডাকশনে ড্যাশবোর্ড সরাসরি উন্মুক্ত করার পূর্বে অবশ্যই Nginx বা Traefik দিয়ে একটি রিভার্স প্রক্সি তৈরি করে Let's Encrypt SSL-এর মাধ্যমে HTTPS সিকিউর করে নিবেন।
