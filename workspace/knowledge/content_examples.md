# Content Examples & Templates: Fluento

This document outlines approved copy formats for various social media posts.

## Facebook Post Template (Educational Tip)

```text
📚 IELTS Writing Task 2 Tip: How to paraphrase effectively!

আইইএলটিএস রাইটিং-এ ভালো স্কোরের জন্য প্রশ্ন প্যারাফ্রেজ করা অত্যন্ত গুরুত্বপূর্ণ। চলুন একটি উদাহরণ দেখি:

❌ Question Text: "Governments should spend more money on public transport."
✅ Paraphrased: "It is argued that state authorities ought to allocate higher budgets to national transit systems."

💡 Key Changes:
- Governments -> State authorities
- Spend money -> Allocate budgets
- Public transport -> National transit systems

আপনার কি রাইটিং নিয়ে কোনো প্র্যাকটিস ফাইল চেক করতে চান? নিচের লিংকে ক্লিক করে আমাদের ফ্রী রাইটিং জেনারেটর ব্যবহার করে দেখুন!
👉 [Link to Free Tool]
```

## YouTube Video Script Structure (IELTS Tip)
- **0:00 - 0:30 (Hook)**: Focus on a specific student struggle (e.g. "Cue card e ki bolbo bhebe pan na?").
- **0:30 - 3:00 (Strategy)**: Give a structured formula (e.g., using the "PPF - Past, Present, Future" strategy for cue cards).
- **3:00 - 4:00 (Live Example)**: Present an actual Band 7.5 speaking response.
- **4:00 - 5:00 (CTA)**: Invite viewers to sign up for a free diagnostic check.
