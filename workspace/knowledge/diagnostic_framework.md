# Student Diagnostic Assessment Framework

This framework is used to evaluate a prospective student's English proficiency level and recommend the appropriate study plan.

## Evaluation Parameters

### 1. Grammar & Syntax Check (লিখিত ব্যাকরণ)
- **Method**: 20-question grammar diagnostic test covering tenses, agreement, and clauses.
- **Grading**:
  - *Score 0-10*: Recommend **English Foundation Course**. Basic sentence formation is not yet stable.
  - *Score 11-15*: Borderline. Can proceed to IELTS if target is low, but foundation recommended.
  - *Score 16-20*: Proceed directly to **IELTS Prep Batch**.

### 2. Lexical Resource & Vocabulary
- **Method**: Synonyms, collocation mapping, and word usage test.
- **Grading**: Identify if student relies heavily on simple words (e.g. bad, good, very) or is able to use contextual academic terms (e.g. detrimental, beneficial, substantial).

### 3. Speaking Confidence & Fluency
- **Method**: 5-minute audio call or recording review (Self-introduction + Cue card response).
- **Grading Indicators**:
  - *Phobia/Hesitation*: Long pauses (> 3 seconds), mother tongue interference. Recommendation: English Foundation.
  - *Flow*: Speaks continuously, minor errors, some vocabulary struggles. Recommendation: IELTS Batch.

### 4. Writing Sample Evaluation (Task 2 Trial)
- **Method**: Student writes a 150-word introduction & body paragraph for a given prompt.
- **Assessment**: Checked against IELTS Task Response, Coherence/Cohesion, Lexical Resource, and Grammar.
- **Action**: Use feedback to highlight the value of expert checking.
