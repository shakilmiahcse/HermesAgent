# Memory: Products - Fluento Course Formats

This file defines the static properties of Fluento's products. For pricing and scheduling updates, query database endpoints.

## Formats Mapped

### 1. Live Batches (সরাসরি ইন্টারঅ্যাক্টিভ ক্লাস)
- **English Foundation**: 2 Months. Focused on grammar mechanics, vocabulary expansion, and confidence building. Includes live classes, daily homework checkups.
- **IELTS Live Prep**: 4 Months. Covers Listening, Reading, Writing, Speaking. Includes live strategy sessions, homework reviews, 1-on-1 speaking mocks.

### 2. Guided Self-Study (সেলফ-স্টাডি কোর্স)
- **English Foundation (Self-Study)**: Video access + quizzes.
- **IELTS Full Course (Self-Study)**: Lecture recordings + automated diagnostic reviews.

### 3. Evaluation Packages (ফিডব্যাক ও অ্যাসেসমেন্ট)
- **Writing Correction**: Detailed assessment of task achievement, coherence, vocabulary, and grammar.
- **Speaking Mock**: 1-on-1 mock exam simulation with detailed band score breakdown report.
