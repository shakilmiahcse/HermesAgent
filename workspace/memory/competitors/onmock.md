# Competitor Profile: OnMock

## Brand
- OnMock is a specialized web platform focused on providing immediate examiner-level mock grading and writing/speaking corrections.

## Pricing
- Pay-per-test mock credits or bundle packages. Check official URLs for latest pricing.

## Courses
- Specialized writing task correction programs, simulated speaking tests, and full 4-module mock prep exams.

## AI Features
- Instant AI evaluation engine simulating IELTS band scoring rubrics.

## Funnel
- Free writing evaluation test leading to paid mock test credit packages.

## Free Tools
- Sample writing feedback and band calculators.

## Strength
- Rapid feedback loops, clean mock exam simulation interface.

## Weakness
- Lacks live human classes, interactive accountability, and direct instructor coaching.

## Positioning
- Instant mock test platform for candidates needing immediate feedback.

## Recent Changes
- Integrated a new writing task assessment layout matching computer-delivered exam settings.
